# Text Summarization

A Streamlit-based AI application that summarizes text and PDF documents using transformer models.

## Features

- Paste text and generate a summary
- Upload `.txt` files
- Upload `.pdf` files
- Choose between DistilBART and BART Large
- Choose short, medium, or long summaries
- Download the generated summary
